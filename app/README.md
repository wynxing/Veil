# Veil 最小应用

本机已验证配置上的托盘原型，不是安装包。Python 3.12 标准库，复用 `tools/display-probe` 的 CCD 与独立恢复进程。

第一组硬件：REDMI Book 14 2025 仅内屏 + 已签名 Virtual Display Driver 25.7.23。不能宣传成不依赖虚拟屏。关屏中睡眠唤醒后不自动再关。

## 运行

在仓库根目录：

```powershell
python app/veil.py
python app/veil.py --check
python -m unittest discover -s app -p "test_*.py" -v
```

`--check` 只枚举并打印门禁，不关屏、不创建托盘。

## 行为

- 窗口列出物理屏。虚拟目标只作为辅助条件显示，不能对它做保持关闭。
- 内屏「保持关闭」要求：已有活动虚拟目标，且独立进程成功注册 `Ctrl+Alt+Shift+F10`。扩展桌面（两个独立桌面）下 CCD 只停内屏会校验 87；本机已验证的是内屏与虚拟目标共用源（克隆）。应用在校验 87 时会先改到该拓扑再关屏。这不是「仅第二屏幕」投影模式。
- 保持关闭期间，热键、托盘「恢复全部」或退出都会回放关屏前拓扑。父进程退出时恢复进程也会点亮内屏。
- 虚拟目标消失时结束保持关闭并尝试 `SDC_TOPOLOGY_INTERNAL`，不回放已失效的双路径拓扑。
- 睡眠或调度中断（worker `execution-gap`）结束保持关闭并重新识别屏幕，不自动再关。内屏已活动时显示已确认。本机操作者已复测确认。
- 不写入持久显示配置，不跨重启自动关屏，不静默安装驱动。

紧急恢复仍可用 `Win+Ctrl+Shift+B`；仍无画面再重启。
