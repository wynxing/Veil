## 日志与故障排查

- App 日志：`%TEMP%\Veil-app.log`，包括操作开始／结束、阶段计时、辅助程序启动／结束／超时及返回码；时间戳为 Unix 秒。
- 驱动助手日志：`%TEMP%\Veil-driver-helper.log`，用于排查安装、启用、禁用与移除。
- 会话目录：`%LOCALAPPDATA%\Veil\session-<id>\`。保留 `events.jsonl`、`heartbeat.json`、`result.json`、`session.json` 与基线文件。
- 反馈时附问题发生时间、应用版本、系统与硬件信息、操作方式和对应日志。会话文件可能包含显示器标识，分享前检查隐私信息。

### 辅助输出未出现

分别检查 MTT PnP 设备是否存在、助手是否成功、Windows 是否产生活动虚拟路径，以及 Veil 是否匹配该路径。`helper enable exit=0` 不能单独证明活动路径已出现。

查看 `vdd-path-wait-end` 的活动路径、虚拟路径和已识别辅助路径数量。虚拟路径未出现时不提交关屏意图，物理屏保持原状；恢复或清理未确认时保留会话和恢复入口。助手超时但仍在运行时，等待它结束，不强杀、不开始第二次设备操作。

### 唤醒后持续闪屏或面板反复出现

关联 `events.jsonl` 的操作编号、`topology-write-start/end`、`cleanup-start/end`、`panel-request`，以及 App/helper 的原生操作和返回码。区分拓扑写入、窗口通知、驱动清理与系统显示事件；不能仅凭窗口通知减少认定硬件闪屏原因已消除。

保留恢复入口，使用面板／托盘「恢复全部」或紧急热键 `Ctrl+Alt+Shift+F10`。恢复结果未知时不显示成功，也不提前禁用辅助输出。

## 已有自动化证据

2026-10-05，1.0.0 发布候选在本机通过 185 项 Rust 单元测试、全工作区 all-targets release 检查、发布预检及正式／预览发布参数回归；WiX MSI 与 Burn 安装包构建均为 0 警告、0 错误。此结果不包含安装包执行或新增机旁测试。

现有回归覆盖：同一恢复结果只消费一次、清理失败保留上下文、失败 heartbeat 通知、执行间隙只回放一次基线、显示电源事件不冒充系统睡眠，以及恢复未确认时的关屏／退出门禁。

等待交互回归覆盖命令入队、重复点击、提交前取消、启用成功但无虚拟路径、恢复失败与清理失败、辅助程序超时后才退出。窗口几何回归覆盖不同缩放比例、负坐标、不同任务栏位置和外接屏消失；这些采用模拟拓扑或几何输入。

历史记录：2026-09-22 本地验证通过 129 项引擎测试、5 项面板几何／动作测试、all-targets 检查、debug 构建及发布预检 12 项。该记录对应当时版本；当前版本以本次实际执行结果为准。

验证命令：

```powershell
cargo test --manifest-path src/Cargo.toml --workspace --locked --release --target x86_64-pc-windows-msvc
cargo check --manifest-path src/Cargo.toml --workspace --all-targets --locked --release --target x86_64-pc-windows-msvc
pwsh -NoProfile -File installer/Test-ReleasePreflight.ps1
```

## 后续机旁检查方法

补充覆盖时，优先检查：待机／合盖唤醒后观察至少 60 秒；UAC 等待和取消；托盘重开；外接屏与混合 DPI、热插拔；新安装、预览版升级、修复及卸载后的屏幕和设备状态。涉及重复问题的场景至少循环 5 次。

记录真实操作与观察结果，并与同一时间段日志关联。自动化模拟、构建和校验和结果分别记录，避免代替物理观察。
