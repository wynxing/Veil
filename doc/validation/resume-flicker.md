# 唤醒闪屏修复验收

基线：`80cfa3b`（0.1.11-preview.1）。本次改动不改变睡醒结束保持关闭的产品选择，不切换渲染后端。

## 故障证据与解释

2026-09-22 本机系统事件显示 Modern Standby；会话在 08:32:01 记录恢复完成且未 reapply，App 在 08:32:02—08:32:28 记录 798 次拉回前台。用户反馈退出 Veil 后闪烁停止。

代码缺陷是：辅助输出清理未完成而保留会话目录时，poll 每次重新消费同一中断结果，重发开面板通知；每帧 refresh 与主动重绘形成高频循环。清理失败的具体原因未被旧日志完整记录。该缺陷不能单独证明所有整屏黑闪均来自窗口操作。

## 离线验收

- 清理失败、取消、超时、枚举失败：连续 100 次轮询仅通知一次，自动清理最多一次，保留真实错误与恢复上下文。
- 恢复失败 heartbeat 无最终结果也通知一次；失败时热键仍可用。显式重试是新操作，旧通知不重放。
- 已确认物理屏恢复时，仅重试辅助输出清理；物理输出丢失则先重新恢复。清理成功后允许新会话。
- 执行间隙只回放一次基线；显示电源熄亮不冒充睡眠；恢复后重复 tick 不重复 APPLY。
- 窗口几何计算覆盖 100%、150%、200% 尺寸、负坐标显示器、顶／左任务栏、外接屏消失、停泊坐标与超大窗口。几何单测不等于真实混合 DPI 或 GPU 验收。

验证命令：`cargo test --manifest-path src/Cargo.toml --workspace --locked`、`cargo check --manifest-path src/Cargo.toml --workspace --all-targets --locked`；构建及结果以交付记录为准。

2026-09-22 本地验证：129 项引擎测试、5 项面板几何／动作判定测试通过；全工作区 all-targets 检查及 debug 构建通过；发布预检脚本 12 项通过。首先在未修复代码上复现了重复通知、失败 heartbeat 漏通知、清理重试重放、执行间隙双回放，以及电源事件误分类和窗口越界测试失败。上述结果不包含 MSI 安装、发布 CI、真实 UAC 或显示硬件验证。
