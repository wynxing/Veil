# Veil 宣传片：宿舍公开放映危机

已确认方向：轻喜剧漫画情境＋屏幕控制示意。首轮交付完整分镜和 8 秒开头样片，画风与节奏确认后再完成全片。

## 创意

你在平板上推剧情，电脑在宿舍替你公开放映。

笑点是私人体验意外出现在旁人面前，不嘲笑玩家。原创角色和宿舍插画，无实拍、无游戏录像。先建立情境，再出现产品。

## 画面与声音

- 1920×1080 横屏、30 fps；首轮样片 240 帧，8 秒。
- 暖色宿舍、薄荷绿衣服、粉色游戏画面和深蓝轮廓。设备和字幕为视觉焦点。
- 角色插画由内置 imagegen 生成；文字、镜头、图形与音效由 Remotion 和可重建的声音脚本控制。
- 重要文字留在画面安全区，静音仍可理解。没有配音。
- 样片声音是工程自行合成的简短节奏与漫画提示音，不使用来源不明的音乐。

## 产品表述

依据当前 README 和 doc/PRD.md，Veil 定位是 Windows 物理屏保持关闭工具，远程软件仅是使用场景。

本片画面是原创动画，不是硬件兼容性或远程软件兼容性证据。不得宣称所有设备面板断电、游戏不中断、零延迟、自动防睡眠或睡醒自动保持关闭。产品镜头完成前再核对具体功能及验证状态。

## 首轮验收

1. 近景阶段看不到电脑游戏画面，拉远后能看出两块屏显示同一角色。
2. 各段字幕不遮挡关键设备，中文正确、无截断、留出阅读时间。
3. 视频确为 8 秒、1080p、30 fps，具有可播放的音轨。
4. 不把动画状态变化写成已验证能力，不修改 Veil 运行时代码。
