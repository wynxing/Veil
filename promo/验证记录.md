# Veil 宣传片验证记录

日期：2026-10-04。

本文保留首轮 8 秒样片记录，并在下方记录 45 秒完整版的最终检查结果。首轮交付时全片尚未制作；其后用户已认可样片。

## 已执行

- `npm.cmd run check`：TypeScript 检查退出码 0。
- 渲染第 60、160、220 帧并逐张检查：近景未露出桌上电脑画面；拉远后两块屏显示同一角色；中文可读、无裁切，关键内容在画面安全区内。
- `npm.cmd run render:sample`：退出码 0，输出 MP4。
- `npm.cmd run still`：退出码 0，输出 1920×1080 封面。
- `ffprobe`：H.264 视频 1920×1080、30/1 fps、240 帧、8.000 秒；AAC 音轨 48 kHz、双声道、8.000 秒。
- `ffmpeg -v error -i out/veil-opening.mp4 -f null NUL`：完整解码退出码 0，无错误输出。
- 音轨 `volumedetect`：平均 -19.0 dB、峰值 -2.4 dB，存在非静音音频；该检查不代表对配乐审美的听感评价。

## 45 秒完整版验证

2026-10-04：用户认可样片并授权直接完成全片。

- `npm.cmd run check`：修复初次编译中的语法遗漏后，重新检查退出码 0。
- `node scripts/render-checks.mjs`：一次打包生成 11 个场景检查帧，退出码 0。逐张检查社死情节、倒带、品牌登场、屏幕选择、保持关闭、主动恢复、夜间双屏、日常双屏、宿舍收尾和片尾；没有中文裁切或关键设备遮挡。
- `npm.cmd run sound:full`：生成 45 秒、48 kHz、双声道原创音轨。
- `npm.cmd run captions`：15 条 UTF-8 SRT 字幕，时序有序且不重叠。
- `npm.cmd run render:full -- --log=error`：退出码 0。
- `npm.cmd run cover:full -- --log=error`：退出码 0。
- 封面采用独立静帧组成，沿用宿舍收尾插画，加入 Veil 标识及标题；不影响全片帧序列。
- ffprobe：视频 H.264、1920×1080、30/1 fps、1350 帧、45.000 秒；AAC、48 kHz、双声道。AAC 编码尾部填充使容器时长为 45.013 秒。
- FFmpeg 完整解码：退出码 0，无错误输出。
- 音量检测：平均 -23.2 dB、峰值 -1.9 dB。4.828–6.360 秒的静音为开头漫画笑点的刻意停顿；没有其它超过 1.2 秒的静音区间。该检查不代表听感审美结论。
- 使用 GitHub 只读查询确认 `wynxing/Veil` 为公开仓库，片尾项目入口有效。

完整版是宣传素材交付，不是 Veil 硬件或远程软件兼容性验收。本次仍没有修改 Veil 运行时代码。
