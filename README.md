# Veil

Veil 是一个 Windows 屏幕开关管理工具，目标是让用户独立控制各显示器的显示状态，并保持设定直到主动恢复。

**项目状态：需求定义阶段。** 当前仓库仅包含产品文档，尚未实现应用、显示控制或硬件兼容性验证，没有可安装版本。

## 希望解决的问题

- 临时熄灭屏幕，需要时通过正常输入唤醒。
- 让指定屏幕保持关闭，直到用户主动恢复。
- 独立管理多台显示器，不影响未选中的屏幕。
- 在后台任务运行时关闭屏幕；是否阻止系统睡眠由独立策略决定。

## 计划能力

显示器识别与列表、按屏幕开启或关闭、临时关闭、保持关闭、单屏恢复、一键恢复全部屏幕，以及紧急恢复入口。

以上均为产品目标。停止桌面输出、面板断电与黑色画面不是同一种能力，实际支持范围以后续技术验证为准。
