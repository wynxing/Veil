# Veil

Veil 是一个 Windows 屏幕开关管理工具，让用户按屏幕独立决定显示或关闭，并保持设定直到主动恢复。它不是全局熄屏快捷方式。临时关闭与保持关闭是两种不同意图。

**项目状态：需求定义阶段，定位与范围已对齐。** 下一阶段是技术验证，不是最小应用。当前仓库仅包含产品文档，尚未实现应用、显示控制或硬件兼容性验证，没有可安装版本。

## 希望解决的问题

- 临时熄灭屏幕，需要时通过正常输入唤醒。
- 让指定屏幕保持关闭，直到用户主动恢复。
- 独立管理多台显示器，不影响未选中的屏幕。
- 在后台任务运行时关闭屏幕；是否阻止系统睡眠由独立策略决定。

若目标硬件无法可靠保持关闭，应禁用该操作或收缩支持范围，不得用全局临时熄屏或黑色覆盖层冒充该能力。

## 计划能力

显示器识别与列表、按屏幕开启或关闭、临时关闭、保持关闭、单屏恢复、一键恢复全部屏幕，以及紧急恢复入口。

以上均为产品目标。首版验收以被选屏幕持续不显示桌面内容为准；面板待机或断电按设备记录，不作为全部设备的必达项。黑色画面不是关屏成功。停止桌面输出、面板断电与黑色画面不是同一种能力，实际支持范围以后续技术验证为准。

在开发机上先证明「仅笔记本内屏」闭环，以下为库存记录，不是已验证兼容性：

- 计算机：XIAOMI REDMI Book 14 2025(FHD+)
- 系统：Windows 11 家庭中文版，64 位，内部版本 26200
- GPU：Intel UHD Graphics，驱动 32.0.101.6733
- 物理显示器：内置面板 TM140VDXP02，1920×1200
- 本机另有 Parsec 虚拟显示适配器，不作为首版关屏验证目标

单外接、内屏加外接、多外接尚未接入，标注未验证。
