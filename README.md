# Veil

Veil 是一个 Windows 屏幕开关管理工具，让用户按屏幕独立决定显示或关闭，并保持设定直到主动恢复。它不是全局熄屏快捷方式。临时关闭与保持关闭是两种不同意图。

**项目状态：技术验证进行中。** 仅内屏第一组已记录，持续关闭闭环未跑通。没有可安装版本，不实现最小应用。

## 希望解决的问题

- 临时熄灭屏幕，需要时通过正常输入唤醒。
- 让指定屏幕保持关闭，直到用户主动恢复。
- 独立管理多台显示器，不影响未选中的屏幕。
- 在后台任务运行时关闭屏幕；是否阻止系统睡眠由独立策略决定。

若目标硬件无法可靠保持关闭，应禁用该操作或收缩支持范围，不得用全局临时熄屏或黑色覆盖层冒充该能力。

## 计划能力

显示器识别与列表、按屏幕开启或关闭、临时关闭、保持关闭、单屏恢复、一键恢复全部屏幕，以及紧急恢复入口。

以上均为产品目标。首版验收以被选屏幕持续不显示桌面内容为准；面板待机或断电按设备记录，不作为全部设备的必达项。黑色画面不是关屏成功。停止桌面输出、面板断电与黑色画面不是同一种能力。

## 第一组验证

硬件库存（开发机，仅笔记本内屏）：

- 计算机：XIAOMI REDMI Book 14 2025(FHD+)
- 系统：Windows 11 家庭中文版，64 位，内部版本 26200
- GPU：Intel UHD Graphics，驱动 32.0.101.6733；当前未检测到虚拟显示适配器
- 物理显示器：内置面板 TM140VDXP02，1920×1200

已记录（详见 [验证结果](doc/validation/redmi-book-14-2025-internal.md)）：

- 能枚举这块内屏；亮屏下保存并恢复显示拓扑成立。
- `SC_MONITORPOWER` 会变成睡眠感黑屏，不能当作关屏后系统继续跑。
- CCD 停用最后一条物理路径被系统拒绝（错误 87）；本机仅内屏上保持关闭不支持。

单外接、内屏加外接、多外接尚未接入，标注未验证。
