# Veil

Veil 是一个 Windows 屏幕开关管理工具，让用户按屏幕独立决定显示或关闭，并保持设定直到主动恢复。它不是全局熄屏快捷方式。临时关闭与保持关闭是两种不同意图。

**项目状态：最小应用可在本机已验证配置上保持关闭并热键恢复。** 第一组硬件采用已签名虚拟屏作为第二目标，再用 CCD 停用内屏。不能宣传成不依赖虚拟屏。关屏中睡眠唤醒后内屏会亮，不自动再关；操作者已复测界面。没有安装包。运行见 [最小应用](app/README.md)。

## 希望解决的问题

- 临时熄灭屏幕，需要时通过正常输入唤醒。
- 让指定屏幕保持关闭，直到用户主动恢复。
- 独立管理多台显示器，不影响未选中的屏幕。
- 在后台任务运行时关闭屏幕；是否阻止系统睡眠由独立策略决定。

若目标硬件无法可靠保持关闭，应禁用该操作或收缩支持范围，不得用全局临时熄屏或黑色覆盖层冒充该能力。

## 计划能力

显示器识别与列表、按屏幕开启或关闭、临时关闭、保持关闭、单屏恢复、一键恢复全部屏幕，以及紧急恢复入口。

以上均为产品目标。首版验收以被选屏幕持续不显示桌面内容为准；面板待机或断电按设备记录，不作为全部设备的必达项。黑色画面不是关屏成功。停止桌面输出、面板断电与黑色画面不是同一种能力。

## 第一组验证

硬件库存（开发机，仅笔记本内屏）：

- 计算机：XIAOMI REDMI Book 14 2025(FHD+)
- 系统：Windows 11 家庭中文版，64 位，内部版本 26200
- GPU：Intel UHD Graphics，驱动 32.0.101.6733
- 物理显示器：内置面板 TM140VDXP02，1920×1200
- 验证用虚拟屏：已安装 Virtual Display Driver 25.7.23（`ROOT\DISPLAY\0000` / VDD by MTT）；单独枚举，不计入物理屏支持范围

已记录（详见 [验证结果](doc/validation/redmi-book-14-2025-internal.md)）：

- 能枚举这块内屏；亮屏下保存并恢复显示拓扑成立。
- Windows 电源事件确认 `SC_MONITORPOWER` 触发了现代待机，不能当作关屏后后台持续运行的证明。
- CCD 停用唯一活动路径在 basic／virtual／refresh 三组校验中均返回 87；当前已测原生路线未实现保持关闭，不代表所有方案均不可能。
- 虚拟屏辅助（第一组保持关闭路线）：已安装官方 VDD 25.7.23。CCD 只停内屏后，15 秒机旁观察为内屏熄灭、普通输入不唤醒、快捷键可恢复；父进程崩溃后独立恢复进程仍能恢复；10 分钟与 20×15 秒循环的系统采样内屏路径保持停用。关屏期间禁用虚拟适配器后保持关闭结束、内屏被点亮。关屏中睡眠唤醒后内屏亮起，保持关闭结束且未自动再关。详见[虚拟屏辅助结果](doc/validation/redmi-book-14-2025-vdd.md)。这不是「仅第二屏幕」投影模式。

单外接、内屏加外接、多外接尚未接入，标注未验证。
