## 本版本

- 关面板或最小化退回托盘：不占任务栏和 Alt-Tab；再开一次 exe 会唤醒已有面板。
- 关最后一块物理屏时，「保持关闭」可确认后安装并启用辅助虚拟输出；面板另有「安装辅助输出」。没有已校验驱动包才禁用。
- 安装器始终写入 MTT / NefCon 文件。`INSTALLVDD=0` 只表示这次不创建设备，以后仍可在面板安装。
- 本机已有同一 `Root\MttVDD` 则写入所有权并接管，不重装第二块。向日葵 / GameViewer 仍不用。
- 驱动包查找包括 Program Files、exe 旁和仓库 `installer/payload`，并核哈希。
- 从 0.1.5 升级：先关掉旧包里会失败的 `RestoreDisplays` 再卸旧版。
- 离线测试已通过。这不是可公开安装，也不是全平台兼容。
